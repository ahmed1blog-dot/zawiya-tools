# الأمان · Security

## نطاق التطبيق

تطبيق محلي: كل المعالجة على جهاز المستخدم. لا يوجد خادم أو API أو تسجيل دخول، ولا تُرفع الملفات أو أسماؤها لأي مكان.

الاتصالان الشبكيان الوحيدان، كلاهما HTTPS إلى GitHub ولا يرسلان أي بيانات عن المستخدم:

1. **التحديث (Sparkle 2):** يقرأ `appcast.xml` من آخر إصدار. كل تحديث موقّع بمفتاح EdDSA، والمفتاح العام مثبت في التطبيق، ويُرفض أي تحديث غير موقّع.
2. **بطاقة الإعلان:** تُجلب من `announcements/banner.json` بجلسة بلا cookies، بحد 64KB ومهلة 10 ثوانٍ. أي ملف لا يطابق القواعد (رابط https فقط، صورة من مجلد `announcements` فقط، حدود للنصوص وتاريخ انتهاء) يُخفي البطاقة.

## ضوابط المعالجة

1. المحركات (FFmpeg وcwebp وzip) تُشغَّل بقائمة وسائط مباشرة، بدون shell، ومن مسارات محددة فقط.
2. FFmpeg مقيّد ببروتوكولات `file,pipe` وقائمة محددة من الصيغ، بدون شبكة أو قوائم تشغيل.
3. محتوى الصور وPDF يُقرأ فعلياً، مع حدود للمقاس وعدد الصفحات والقيم الرقمية. الملف بامتداد مزيّف يفشل بدون إنشاء نتيجة.
4. العمل داخل مجلد مؤقت عشوائي بصلاحية 0700، والنتائج 0600. النشر ذري ولا يستبدل أي ملف موجود؛ الأصل لا يُلمس أبداً.
5. الإلغاء والمهلة ينهيان العملية التابعة، وتُحذف فقط الملفات التي أنشأتها المهمة.
6. إنشاء ZIP يرفض الكتابة داخل المجلد المصدر ولا يتتبع الروابط الرمزية.

## المحركات المضمّنة

FFmpeg 9.0.2 (موقّع وموثّق من Apple) وcwebp 1.6.0 من Google، بنسخ مثبتة يُتحقق منها بـSHA-256 في `vendor/fetch-engines.sh`.
