# لوحة الإعلانات / Announcement banner

عدّل `banner.json` من GitHub مباشرة (زر القلم ✏️ ثم Commit). يظهر التغيير عند كل المستخدمين خلال 6 ساعات أو عند فتح التطبيق.

| الحقل | الوصف | الحد |
|---|---|---|
| `enabled` | `true` لعرض البانر، `false` لإخفائه عند الجميع | — |
| `id` | غيّره مع كل إعلان جديد؛ يعود الظهور لمن أغلق الإعلان السابق | 64 حرفاً |
| `title_ar` / `title_en` | العنوان | 60 حرفاً |
| `body_ar` / `body_en` | النص | 160 حرفاً |
| `cta_ar` / `cta_en` | نص الزر | 24 حرفاً |
| `url` | رابط الزر، يجب أن يبدأ بـ `https://` | — |
| `image` | اختياري: صورة PNG/JPG داخل مجلد `announcements` في هذا المستودع فقط (رابط raw.githubusercontent.com). المقاس المقترح 640×200 | 1MB |
| `expires` | تاريخ انتهاء العرض بصيغة `YYYY-MM-DD` | — |
| `platforms` | `mac` و/أو `windows` | — |

التطبيق لا يرسل أي بيانات عن المستخدم عند جلب الإعلان، ويتجاهل أي ملف لا يطابق هذه القواعد.
